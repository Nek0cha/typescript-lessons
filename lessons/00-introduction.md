# TypeScriptは「型のチェックをしてくれるJavaScript」

TypeScriptは、JavaScriptに型（型注釈・type annotation）を追加した言語です。書いたコードは最終的にJavaScriptに変換（コンパイル）されて動くので、実行環境そのものはJavaScriptと同じです。違うのは、コードを書いている最中に「この値は本当はどんな種類のデータか」をチェックしてくれる点にあります。

具体例で見てみます。次はJavaScriptのコードです。

```javascript
function addTax(price) {
  return price * 1.1;
}

addTax("1000"); // エラーにならない。結果は "10001000000..." のような文字列の連結になる
```

`price`に文字列の`"1000"`を渡しても、JavaScriptは何も言わずに実行してしまいます。数値のつもりで書いた関数に文字列を渡すという典型的なミスですが、実行するまで気づけません。

同じ関数をTypeScriptで書くとこうなります。

```typescript
function addTax(price: number): number {
  return price * 1.1;
}

addTax("1000"); // ここでエディタが赤線を出す。コンパイルも失敗する
// Argument of type 'string' is not assignable to parameter of type 'number'.
```

`price: number`という書き方が型注釈です。「この引数は数値でなければいけない」とTypeScriptに伝えると、文字列を渡した瞬間にエディタが警告を出してくれます。実行する前に、書いている最中に気づけるというのがポイントです。

## なぜ型があると開発が楽になるのか

型の恩恵は、コードが小さいうちはあまり実感できません。関数が3つしかないプログラムなら、頭の中で全部覚えていられるからです。効果が出てくるのは、コードの量が増えたときと、複数人（あるいは複数のライブラリ）が絡んだときです。

- 関数を呼ぶときに、エディタが「この引数は何を渡せばいいか」を教えてくれる（補完が効く）
- 3か月前に自分が書いたコードを読み返すとき、型を見れば引数や戻り値の形がすぐ分かる
- 他人が書いたライブラリを使うときも、型定義があれば説明書を読まなくてもだいたいの使い方が分かる

このシリーズの最終目標であるDiscord Botの開発では、Discordから送られてくるメッセージやユーザー情報など、扱うデータの種類が多くなります。型がないまま書くと「このオブジェクトに`username`というプロパティが本当にあるんだったか」を毎回コードを遡って確認する羽目になりますが、型があればエディタが即座に教えてくれます。

## JavaScriptを知らなくても大丈夫

「TypeScriptの前にJavaScriptを勉強しないといけないのでは」と思うかもしれませんが、このシリーズではその必要はありません。TypeScriptの文法はJavaScriptの文法を土台にしているため、TypeScriptを学べば自然とJavaScriptの基礎も身につきます。逆に、TypeScript特有の型の書き方だけを後から追加で学ぶより、最初から型と一緒に学んだほうが遠回りになりません。

## このシリーズで扱わないこと

型システムには非常に高度な機能（ジェネリクスの複雑な組み合わせ、条件型など）もありますが、このシリーズでは扱いません。目標はあくまで「Discord Botを自分の手で動かせるようになる」ことなので、そこに必要な範囲に絞っています。より深い型の話は、Bot開発に慣れたあとで公式ドキュメント（[typescriptlang.org](https://www.typescriptlang.org/docs/)）を読むことをおすすめします。
